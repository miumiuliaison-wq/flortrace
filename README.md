## 默认配置与路线

学校默认**合肥工业大学（ID 100）**，账号与密码填写自己的信息。首次内置“翡翠湖操场·默认路线”（约 384.3 米），直接作为当前路线并加入收藏；升级不覆盖已有自绘路线。

内置路线已获用户明确授权公开，仅含手绘路线几何与学校、校区信息，不含账号或个人运行记录。其他学校用户需修改学校配置并自行选择场地、绘制路线，不能将内置路线当作其他学校的有效路线。

## 在软件里保存与调用

1. 在路线页拖动、缩放地图，填写并确认实际校区或操场。
2. 点击“画路线”，逐点绘制并点击起点闭合；也可编辑节点或预览外扩。
3. 在“预览保存”中填写路线名称，点击**保存并使用**，路线会保存在应用内收藏并成为当前路线。
4. 在“选校区”的收藏列表中选择路线，点击**使用这条路线**即可切换，不会开始跑步。有未保存修改时会先提示确认。

同名不同路线请改用不同名称；相同路线不会重复收藏。收藏只在本机保存，卸载会删除用户新画的路线，重新安装仅恢复内置默认路线。地图搜索及文件导入导出入口已移除，无需导入文件才能使用收藏。

## 编号圆圈与重要提醒

地图优先显示有效任务缓存中的打卡点与范围圆。翡翠湖区域没有缓存时，也会显示 6 个离线参考点和 20 米参考范围（2026-10-31 历史样例，非实时），并始终标明“离线参考”。参考范围只用于画路线，不能代表当前任务的有效范围。

点击编号圆圈可查看编号、半径并定位；编号点和范围圆可分别隐藏。SVG 按米绘制范围，编号圆心与外圈分开显示；操作不会改变官方判定，也不会自动登录。

按开发进度持续维护，不承诺固定更新周期；没有新增自动更新服务。公开版不保证后台持续运行、所有学校任务兼容或最终审核通过。
