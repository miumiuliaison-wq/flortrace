循路而行，记录日常。蓝白花卉主题的个人开发客户端。

## 下载与安装

当前版本 **2.3.4**，适配云运动 3.6.7。Release 提供一个同时包含 arm64-v8a、armeabi-v7a 的通用 APK，Android 7.0 及以上系统可安装。

已有用户请直接覆盖安装，保留账号、路线和历史；不要先卸载。APK 的 SHA-256 见对应 Release 说明。

本仓库只分发 APK 和说明，不提供开发源码、账号配置、个人轨迹或历史数据。GitHub 自动生成的 Source code 压缩包只包含本仓库的公开说明文件，并非应用源码。

## 开始之前

1. **千万不要申诉。** 请先阅读完整[使用方法](USAGE.md)。
2. 本应用不向开发者收集或上传账号、密码及运行记录；登录、查询和运行的必要信息会发送至配置的服务端。地图与搜索请求会发送至相应地图服务。
3. 本客户端登录可能使官方云运动旧会话失效，重新登录即可，此现象不一定发生在任务结束后。
4. 本机完成仅表示接口已接受，不代表官方审核通过。运行期间保持应用前台亮屏。

## 功能与更新

- 地图选校区、逐点绘制、路线预览保存及按米外扩。
- 手动启动，运行互斥，结束或失败后允许再次操作；服务端限制仍有效。
- 本机月历按天标记，保留完整本机成功记录。
- 本地字体与花卉界面资源，说明页可离线阅读。

按开发进度在本仓库持续维护和发布更新，不承诺固定周期；本次没有新增自动更新服务。公开版未保证后台持续运行，也不保证官方最终审核结果。
